# TANGO+｜2学期中間対策

アップロードされた「tangosta_100_questions_4sheets(1).pdf」から、実際に掲載されている95問を使った学習アプリです。元資料には41〜45番が掲載されていません。

## 使い方

- `index.html` を Chrome、Edge、Safari などで開いてください。インターネット接続は不要です。
- ホームで学習範囲を選び、回答して「答え合わせ」を押します。
- 範囲1・2は4択、日本語→英語（46〜55）・範囲3・5はスペル入力、範囲4は語句タップ式の並び替え、範囲6は音節タップによるアクセント選択です。
- 間違えた問題は「間違いを復習」、残しておきたい問題は「お気に入り」で復習できます。
- 学習履歴はブラウザのローカルストレージに保存されます。端末やブラウザを変更すると引き継がれません。プライベートモードでは消える場合があります。

## 公開する場合

GitHub Pages に `index.html` を置くだけでサイトとして公開できます。追加のサーバーや依存ライブラリは不要です。
